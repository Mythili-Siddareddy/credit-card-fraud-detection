# Credit Card Fraud Detection

## Description

This project uses machine learning techniques to detect fraudulent credit card transactions based on transaction patterns.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)

## Files

* Project Report
* Code file

## Results

The model achieved good accuracy and was able to identify fraudulent transactions effectively, even with imbalanced data.
